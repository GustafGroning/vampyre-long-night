## Utanför beslutet

- Den gamla `rounds.rng_seed` och övriga gamla tabeller rörs inte. De används inte av servern. Städning i BACKLOG.
- Content per kampanj (B4) finns inte: både server och klient använder `DEFAULT_CONTENT`.
